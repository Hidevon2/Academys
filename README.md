# Herbal-Ai Code Academy (Next.js)
SoloLearn-style lessons built from the Herbal-Ai capstone code. 4 courses x 100 lessons.

## Run
npm install
npm run dev     # http://localhost:3000

## Deploy to Vercel
Push to GitHub, then import the repo on vercel.com (Framework: Next.js). No env vars needed.

Lesson data lives in data/lessons.json. Progress is saved in the browser (localStorage).
